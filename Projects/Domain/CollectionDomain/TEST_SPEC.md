## 컬렉션 좋아요

`Tests/Entity/CollectionDetailTests.swift`

- 좋아요하면 좋아요 수가 하나 는다
- 이미 좋아요했으면 다시 좋아요해도 그대로다
- 좋아요를 취소하면 좋아요 수가 하나 준다
- 좋아요하지 않았으면 취소해도 그대로다
- 좋아요 수가 0이면 취소해도 0 아래로 내려가지 않는다
- 좋아요한 컬렉션에서 좋아요를 전환하면 취소된다
- 좋아요하지 않은 컬렉션에서 좋아요를 전환하면 좋아요가 된다

## 컬렉션 만들기·수정하기

`Tests/Entity/CollectionDraftTests.swift`

- 이름이 있고 작품이 하나 이상이면 설명이 없어도 제출할 수 있다
- 이름이 비었거나 공백뿐이면 제출할 수 없다
  - `""` — 아무것도 쓰지 않음
  - `"   "` — 스페이스만
  - `"\n\t "` — 줄바꿈·탭도 공백으로 본다
- 작품이 하나도 없으면 제출할 수 없다
- 이름은 20자까지 입력할 수 있다
- 이름이 20자를 넘으면 거부하고 이전 이름을 지킨다
- 남은 이름 글자 수는 20에서 지금 길이를 뺀 값이다
- 설명은 60자까지 입력할 수 있다
- 설명이 60자를 넘으면 거부하고 이전 설명을 지킨다
- 남은 설명 글자 수는 60에서 지금 길이를 뺀 값이다
- 수정하기를 열면 저장된 컬렉션 내용이 그대로 채워진다
- 설명이 없던 컬렉션은 수정하기를 열면 설명이 비어 있다
- 저장된 컬렉션이 제한을 넘으면 넘는 부분을 잘라 채운다
- 작품을 추가하면 목록 끝에 붙는다
- 이미 담긴 작품은 다시 추가할 수 없다
- 작품이 100개면 더 추가할 수 없다
- 작품을 빼면 목록에서 사라진다
- 작품 목록을 새 목록으로 통째로 바꿀 수 있다
- 새 목록이 100개여도 통째로 바꿀 수 있다
- 새 목록이 100개를 넘으면 바꿀 수 없다
- 새 목록에 같은 작품이 두 번 있으면 바꿀 수 없다
- 담긴 작품을 대표로 고를 수 있다
- 담기지 않은 작품은 대표로 고를 수 없다
- 대표를 고르지 않았으면 첫 작품이 대표다
- 대표를 골랐으면 고른 작품이 대표다
- 작품이 없으면 대표도 없다
- 대표로 고른 작품을 빼면 대표 선택도 풀린다
- 대표로 고르지 않은 작품을 빼면 대표 선택은 그대로다
- 대표로 고른 작품이 새 목록에 없으면 대표 선택도 풀린다
- 대표로 고른 작품이 새 목록에도 있으면 대표 선택은 그대로다
- 새 컬렉션은 모두에게 보인다
- 꺼진 나만 보기를 누르면 켜진다
