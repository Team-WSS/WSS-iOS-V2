## 서재 요청 개수

`Tests/Entity/LibraryPageSizePolicyTests.swift`

### 다시 들어올 때 보던 만큼 받기

- 보던 개수만큼 다시 요청한다
- 아직 한 페이지를 다 받지 못했으면 한 페이지(15개)를 요청한다
  - `0` — 아무것도 못 받음
  - `14` — 한 페이지에서 하나 모자람
- 보던 개수가 100개를 넘으면 100개에서 자른다
  - `100` — 딱 상한
  - `101` — 상한에서 하나 넘음

### 그사이 늘어난 만큼 더 받기

- 비운 사이 늘어난 만큼만 이어서 요청한다
- 늘지 않았거나 줄었으면 이어서 요청하지 않는다
  - `25` — 그대로(0개 늘어남)
  - `22` — 3개 줄어듦
- 다음 페이지가 없으면 늘었어도 이어서 요청하지 않는다
- 늘어난 개수가 100개를 넘으면 100개에서 자른다
  - `110` — 100개 늘어남(딱 상한)
  - `111` — 101개 늘어남(상한에서 하나 넘음)

## 내 서재 필터

`Tests/Entity/MyLibraryFilterTests.swift`

### 관심

- 관심은 누를 때마다 켜지고 꺼진다
  - `(false, true)` — 꺼져 있으면 켜진다
  - `(true, false)` — 켜져 있으면 꺼진다

### 독서 상태

- 독서 상태를 고르면 담긴다
- 이미 고른 독서 상태를 또 고르면 그대로다
- 고른 독서 상태를 빼면 사라진다

### 장르

- 장르를 고르면 담긴다
- 이미 고른 장르를 또 고르면 그대로다
- 고른 장르를 빼면 사라진다

### 매력 포인트

- 매력 포인트를 고르면 담긴다
- 이미 고른 매력 포인트를 또 고르면 그대로다
- 고른 매력 포인트를 빼면 사라진다

### 키워드

- 키워드를 고르면 담긴다
- 이미 고른 키워드를 또 고르면 그대로다
- 고른 키워드를 빼면 사라진다

### 연재 상태

- 연재 상태는 하나만 고를 수 있어 새로 고르면 바뀐다
- 연재 상태 선택을 해제하면 아무것도 선택되지 않은 상태가 된다

### 별점

- 고른 별점 범위가 담긴다
  - `(1.0, 3.0)` — 보통 범위
  - `(2.0, 2.0)` — 최소와 최대가 같아도 범위다
- 별점 범위가 0점에서 5점 밖이면 안으로 맞춘다
  - `(-1, 3, 0, 3)` — 최소가 0점 아래
  - `(1, 6, 1, 5)` — 최대가 5점 위
- 최소가 최대보다 크면 받지 않고 이전 별점 범위를 지킨다
- 0점에서 5점 전체를 고르면 별점 필터가 없다
  - `(0, 5)` — 딱 전체 범위
  - `(-1, 6)` — 안으로 맞추면 전체 범위가 된다
- 별점 없는 작품만 보기를 고르면 별점 범위 대신 걸린다
- 별점 필터를 해제하면 아무 별점 범위도 선택되지 않은 상태가 된다

### 정렬

- 내 서재의 초기 정렬 타입은 등록 최신순이다
- 내 서재의 정렬 타입을 변경할 수 있다

### 초기화

- 초기화하면 시트 필터(독서 상태·장르·연재 상태·별점·매력 포인트·키워드)를 모두 비운다
- 초기화해도 관심과 정렬은 그대로 둔다

### 필터 표시

- 시트 필터 중 하나라도 걸리면 필터가 걸린 상태다
  - `MyLibraryFilter(readingStatus: [.watching])` — 독서 상태
  - `MyLibraryFilter(genres: [.fantasy])` — 장르
  - `MyLibraryFilter(publicationStatus: .completed)` — 연재 상태
  - `MyLibraryFilter(rating: .unratedOnly)` — 별점
  - `MyLibraryFilter(attractivePoint: [.worldview])` — 매력 포인트
  - `MyLibraryFilter(keywords: [regression])` — 키워드
- 관심이나 정렬만 바꿨으면 필터가 걸린 상태가 아니다

## 작품 상세의 대표 독서 상태

`Tests/Entity/NovelInformationTests.swift`

- 읽은 사람이 없으면 대표 독서 상태가 없다
  - `[:]` — 독서 상태 수가 비어 있음
  - `[.watching: 0, .watched: 0, .quit: 0]` — 모두 0명
- 가장 많이 고른 독서 상태가 대표가 된다
- 수가 같으면 보는 중, 봤음, 하차 순으로 대표를 정한다
  - `([.watching: 6, .watched: 6, .quit: 4], .watching)` — 보는 중 = 봤음이면 보는 중
  - `([.watching: 2, .watched: 6, .quit: 6], .watched)` — 봤음 = 하차면 봤음
