## 닉네임 입력

`Tests/Entity/NicknameDraftTests.swift`

### 입력 길이

- 닉네임은 10자까지만 입력된다
- 10자를 넘겨 쳐도 잘린 결과가 같으면 중복 확인 결과가 그대로다

### 입력 상태

- 닉네임이 비어 있으면 아직 입력 전 상태다
- 처음 닉네임과 같으면 바뀌지 않아 쓸 수 없다
- 다른 닉네임을 쳤다가 처음 닉네임으로 되돌리면 바뀌지 않아 쓸 수 없다
- 공백·줄바꿈·탭이 들어가면 쓸 수 없다
  - `"새 이름"` — 가운데 공백
  - `"새이름\n"` — 줄바꿈
  - `"새\t이름"` — 탭
- 공백이 들어가 있으면 처음 닉네임과 같아도 공백 때문에 쓸 수 없다고 알린다
- 한 글자이거나 한글·영문·숫자 말고 다른 문자가 있으면 쓸 수 없다
  - `"가"` — 한 글자 — 두 글자부터 쓸 수 있다
  - `"새이름!"` — 특수문자
  - `"ㄱㄴㄷ"` — 완성되지 않은 한글(자음만)
- 두 글자이고 규칙에 맞으면 중복 확인이 필요하다

### 중복 확인

- 중복이면 쓸 수 없다
- 중복이 아니면 쓸 수 있다
- 확인하는 사이에 닉네임이 바뀌었으면 늦게 온 결과는 버린다
- 중복 확인 뒤 닉네임을 고치면 다시 확인해야 한다

## 프로필 수정

`Tests/Entity/ProfileDraftTests.swift`

### 바뀐 것 알아보기

- 처음에는 바뀐 것이 없다
- 다른 캐릭터를 고르면 캐릭터가 바뀐 것이다
- 같은 캐릭터를 다시 고르면 캐릭터가 바뀐 것이 아니다
- 닉네임은 중복 확인까지 통과해야 바뀐 것이다
  - `(NicknameDraft.DuplicationCheckState.notYet, false)` — 확인 전
  - `(.duplicated, false)` — 중복
  - `(.notDuplicated, true)` — 통과
- 소개글을 고쳤다가 처음대로 되돌리면 바뀐 것이 아니다
- 장르를 넣었다 빼서 처음과 같아지면 바뀐 것이 아니다

### 저장 가능 여부

- 아무것도 안 바꾸면 저장할 수 없다
- 캐릭터·닉네임·소개글·장르 중 하나만 바꿔도 저장할 수 있다
  - `Edit.allCases`
- 닉네임이 확인 전·중복·공백·규칙 위반이면 다른 걸 바꿔도 저장할 수 없다
  - `BlockingNickname.allCases`

### 소개글

- 소개글은 50자까지만 입력된다
  - `(50, 50)` — 딱 50자는 그대로
  - `(51, 50)` — 넘치면 50자로 자른다
- 저장 직전에 소개글을 세 줄까지만 남긴다
  - `("하나\n둘\n셋", "하나\n둘\n셋")` — 세 줄은 그대로
  - `("하나\n둘\n셋\n넷", "하나\n둘\n셋")` — 넷째 줄부터 버린다

### 선호 장르

- 장르를 고르면 담긴다
- 고른 장르를 빼면 사라진다
